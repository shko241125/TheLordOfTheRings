# 모리아의 그림자 (구역 1: 서문 → 트롤 굴 · 구역 2: 21번째 홀 · 구역 3: 마자르불의 방 · 구역 4: 대장간 · 구역 5: 크하잣둠의 다리)

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 단위·이동 테스트 + 결정성 회귀 테스트
npm run build        # 타입 검사 + 프로덕션 빌드
npm run smoke        # 실제 브라우저 스모크: 개발 서버(새 게임 → 문 → 화로 저장 → 새로고침 → 이어하기) + 배포 빌드(부팅·이동), WebGPU·WebGL2, 콘솔 에러 0
npm run perf         # 성능 예산 측정: 구역 5개의 방마다(+발로그전) Low·High로 draw call·광원·그림자 광원·틱 p95 (예산 초과면 종료 코드 1)
                     #   npm run perf -- webgl zone5  → WebGL2 경로, 한 구역만
                     # 브라우저 경로는 CHROME_PATH (기본 /usr/bin/google-chrome)
```

비공식 비상업 팬 게임이다(시작·일시정지 화면에 고지). 원작 고유명사는 `data/lore.json`에 모여 있어, 값을 바꾸고 다시 빌드하면 게임 안의 이름이 모두 바뀐다(조사 받침은 직접 확인).

화면의 키 표시(하단 행동 칸, 상호작용 안내)는 마지막으로 쓴 장치를 따른다: 키보드를 누르면 키 이름, 게임패드를 쓰면 패드 버튼(↑ ↓ ← A, LT+RT), 터치 화면에서는 비운다.

패드 Start로 게임에 돌아오면 포인터 잠금이 걸리지 않는다(브라우저는 패드 버튼을 잠금을 걸 수 있는 사용자 동작으로 치지 않는다). 마우스 시점은 화면을 한 번 클릭하면 다시 걸린다.

Esc(일시정지) 화면이나 그 안의 창(스킬·장비·일지·지도·상점·대화), 두린의 문 수수께끼 창이 열려 있는 동안은 게임 시간이 멈추고 소리가 작아진다.
Esc(일시정지) 화면의 ⚙ 설정: 화면 흔들림, 돌의 감각 음파 세기, 밝기, 글자 크기, 마우스 감도·상하 반전,
색각 보정(빨강·주황 신호 → 노랑·하늘색), 난이도(스토리: 받는 피해 ½·패링 창 2배 / 쉬움: ¾ / 보통 / 어려움: 1.5배 — 용암은 어느 난이도든 즉사, 보통이 아니면 HUD 레벨 줄에 표시), 키 배치 바꾸기. 브라우저에 저장된다. `?shake=0`은 설정과 상관없이 흔들림을 끈다.

## 진행

화면 왼쪽 위에 지금 목표가 한 줄로 뜬다(구역마다 메인 퀘스트 하나 — 일지 J에서 전체를 본다).
음악은 북소리 디렉터를 따라간다: 조용할 때는 낮은 드론만, 북이 다가오면 떨리는 현이 깔리고 절정에서 가장 커진다. 보스와 싸우는 동안은 낮은 금관이 숨 쉬듯 부풀어 오르고(트롤은 느릿하게, 대장은 한 음 높고 빠르게, 발로그는 한 옥타브 아래에서 깊게), 보스를 쓰러뜨리면 장조 화음이 울린다(발로그는 저음이 심연으로 미끄러져 내려간다).
어둠 속에서는 소리가 두 번째 시야다: 고블린이 알아채는 외침, 휘두르기, 활시위 소리가 난 쪽에서 들린다 (헤드폰 권장).
서문 밖에서 시작한다. 문 앞에서 E → 비문의 수수께끼에 답하면 문이 열린다 (60초가 지나면 간달프가 힌트를 준다).
화로에서 E로 쉬면 체력·예비 횃불이 차고 저장된다. 새로고침하면 마지막 화로에서 이어한다. 설정 창의 '저장 내보내기'로 저장을 파일(`moria-save.json`)로 받아 두고, '저장 가져오기'로 되살린다 (브라우저 데이터를 지웠거나 다른 브라우저로 옮길 때). 시작 화면의 '새 게임'은 저장을 지우기 전에 한 번 묻는다.

트롤 굴의 동굴 트롤(중간 보스): 내려찍기는 바닥의 붉은 고리로 1초 예고되고 패링할 수 없다 — 옆으로 피한다.
기둥을 내려찍게 만들면 기둥이 부서지며 트롤이 오래 휘청인다(반격 기회). 휘두르기는 기둥 뒤에 숨으면 막히고, 패링할 수 있다.
트롤은 빛에 끌린다 — 횃불을 던지면 그쪽으로 가서 내려찍는다.

북소리가 절정에 이르면 굴 입구에서 고블린 물결(구역 1: 40마리)이 쏟아진다. 무리는 횃불빛(밝기 0.5, 약 5.7m) 안으로 들어오지 않고,
경계 밖 어둠에서 한 마리씩 진짜 고블린이 되어 덤빈다 (동시 공격은 여전히 2마리).
물결은 기둥 홀 양옆 고블린 굴에서 나온다. 굴 입구의 금 간 기둥(균열이 주황빛)을 부수면 넘어지며 무리를 깔아뭉개고 굴을 막는다
(넘어지는 자리에 서 있으면 맞는다). 적을 쓰러뜨리면 동료 게이지가 차고, Q로 종족의 동료를 부른다.

동굴 트롤을 쓰러뜨리면 트롤 굴 북쪽 통로가 21번째 홀로 이어진다 (구역을 옮길 때 저장하고 다시 부팅한다).
21번째 홀에서는 기둥 사이 등불 셋을 E로 밝히면 북문이 열린다. 벽을 따라 선 고블린 궁수는 0.8초 활을 당긴 뒤 쏜다 —
기둥 뒤에 숨거나 회피로 피한다(패링 불가). 북문 앞의 고블린 대장: 3연타는 패링하면 끊기고, 돌진은 바닥의 붉은 띠로 예고된다(패링 불가, 옆으로 피하기,
벽에 박히면 휘청). 체력이 절반이면 휘파람으로 무리를 부른다. 등불 셋 + 대장 처치 → 북문 너머 마자르불의 방.
마자르불의 방: 가운데 발린의 무덤에서 E → 방어전 3물결이 양옆 굴에서 쏟아진다. 굴 입구의 금 간 기둥을 무너뜨리면 그쪽 굴이 막혀
한쪽만 지키면 된다. 우루크는 방패로 앞에서 온 약공격을 막는다(20%) — 강공격이나 패링 뒤 반격으로 방패를 깨거나 옆·뒤를 친다.
3물결을 막으면 북쪽 쇠문이 열리고 대장간으로 내려간다.
21번째 홀 북동 구석의 광부 핀(E)을 동쪽 층계 화로까지 데려가면(호위 — 적 곁에서 다친다) 동료 게이지가 영구히 25% 빨리 찬다.
NPC 곁에서 E를 누르면 대화가 열린다(선택지는 클릭 또는 숫자 키 1~3) — 말은 진행에 따라 바뀌고, '물건을 보자'에서 상점으로 간다.
상인 노리(구역 2·4)에게서 예비 횃불·미스릴·장비 꾸러미를 금화로 산다(곁에서 E). 대장장이 그로르(구역 4)는 모루가 타오른 뒤
전설 무기 '두린의 도끼'를 벼려 주고, 곁에서 강화도 해 준다.
대장간: 용암 강을 돌다리 둘로 건넌다(떨어지면 끝 — 용암빛 때문에 다리 위에서는 건너편 궁수에게 잘 보인다).
모루 둘레 발판 셋을 한꺼번에 눌러야 모루가 다시 타오르고 북쪽 쇠문이 열린다 — 횃불을 발판에 내려놓고(F) 마지막 발판에 선다.
모루 + 우루크 대장 처치 → 크하잣둠의 다리로 내려간다.
크하잣둠의 다리: 남쪽 통로 화로 곁에 종족의 동료(아라곤·김리·레골라스)가 기다린다 — 대화(E)로 발로그전 요령을 듣는다.
두 번째 홀에 들어서면 뒤에서 불의 벽이 다가온다 — 질주를 섞어 다리까지 달린다. 다리 앞에서 발로그가 불 속에서 나온다.
발로그는 평소에 25%만 맞는다. 바닥의 붉은 띠(내리찍기)를 피하면 칼이 다리에 박혀 가슴이 열린다 — 그때 친다.
한쪽 날개가 들리면 웅크려(C) 버틴다(난간 없는 다리). 체력 40%부터 채찍과 불의 고리(회피로 뚫기). 10%가 되면 간달프가 "다리를 건너라!" 하고 기다린다 —
다리를 건너가면 간달프가 다리를 내리치고(서쪽 토막이 무너진다) 발로그가 떨어진다. 동문으로 나가면 엔딩이다.
바닥의 빛바랜 양피지(마자르불의 책 조각)를 E로 주우면 원정대의 기록 한 장을 읽는다(12조각 모두 놓았다 — 다 모으면 전설 장신구 '발린의 인장').
적을 쓰러뜨리면 XP가 쌓이고(고블린 10, 무리 2, 우루크 30, 트롤 150, 발로그 500), 레벨업마다 체력·피해가 조금 오르고 스킬 포인트 1을 받는다.
스킬 트리는 종족마다 3갈래 × 5단계, 되돌리기는 밝힌 화로 곁에서 무료.
적은 금화(자동 줍기)와 장비(E로 줍기)를 떨어뜨린다. 장비 6칸 · 등급 5단계(일반·정교·희귀·장인·전설) — 어둠에 오래 머물수록 좋은 등급이 나온다(빛의 도박).
보스는 희귀 이상 장비 + 미스릴을 준다. 밝힌 화로 곁에서 미스릴 + 금화로 +1~+5 강화(실패 없음).

쓰러지면 마자르불의 책에 원정대 기록 문체로 한 줄이 남고, B로 쓰러지기 전 60초를 다시 볼 수 있다
(Space 0.25× 슬로우, 마우스로 카메라, R 다시 보기, Enter 게임으로). 입력만 기록해 결정적 시뮬레이션으로 되살린다.

## URL 옵션

- `?new=1` — 저장 지우고 새 게임
- `?touch=1` — 터치 조작 강제 (터치 기기에서는 자동: 왼쪽 드래그 이동 · 오른쪽 드래그 카메라 · 버튼, 적이 가까우면 자동 락온)
- `?quality=low|medium|high` — 품질 고정 (기본 자동: 기기로 고르고 처음 5초 FPS가 40 미만이면 한 단계씩 낮춘다)
- `?zone=test` — M0~M1 시험 방 (결정성 골든·전투 검증용, 저장 안 함)
- `?class=human|dwarf|elf` — 클래스 (키·속도·복장이 다르다)
- `?rig=ual|kaykit` — 캐릭터 에셋 비교 (기본 ual: 사실적 비율 / kaykit: SD 비율)
- `?backend=webgl` — WebGL2 폴백 강제

## 구조

- `src/core` — 고정 60Hz 루프, 시드 난수, 결정적 삼각함수·atan2, 입력(키보드·마우스·게임패드)
- `src/sim` — 결정적 시뮬레이션 (three.js·DOM 의존 없음, Node에서 실행 가능). 브라우저는 내비메시를 `src/navWorker.ts`(웹 워커)에서 굽는다
  - `player.ts` 이동·행동(콤보·강공격·엘프의 활·회피·패링·스태미나·입력 버퍼·락온), `combat.ts` 수치·판정, `archer.ts` 화살(고블린 궁수·엘프)

## 결정성 규칙

1. 게임 로직은 `stepSim` 안에서만, dt = 1/60 고정
2. `Math.random` 금지 → `core/rng.ts`
3. 시뮬레이션에서 `Math.sin/cos/atan2` 금지 → `core/trig.ts` (정수 각도, 1회전 = 4096)
4. Rapier 바디는 `level.solids` 배열 순서대로 생성
5. 애니메이션은 렌더 전용 — 시뮬레이션은 상태만 내보내고, 공격 클립은 타격 순간을 판정 틱에 맞춰 시간 왜곡한다
6. navcat은 `findPath`만 쓴다 — crowd 모듈은 `Math.sin/cos`를 써서 엔진마다 결과가 다를 수 있다
